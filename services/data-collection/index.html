Data Collection: common questions

How do you make sure we get the demographics we asked for?

We set quotas per language, region, age group and gender at the start and track them live. Slots close automatically when a quota is filled, so the dataset stays balanced.

Do you collect data in the wild or in controlled conditions?

Both. We can run guided remote collection from contributors' own devices, or controlled sessions when conditions must be tightly specified.

Who owns the data?

You do. Rights and licensing are defined in the contract and contributor agreements before collection starts.
